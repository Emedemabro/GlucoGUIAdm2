# GlucoGuía PWA

Interfaz web progresiva estática. No requiere instalar dependencias ni ejecutar un paso de compilación.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube los archivos de este proyecto a la raíz.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, la rama que contiene los archivos y la carpeta raíz (`/root`).
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.

La instalación y el modo sin conexión de la PWA requieren HTTPS; GitHub Pages proporciona HTTPS para los sitios publicados.
